# M10 Path Query Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add bounded two-hop ego graph expansion and explainable two-entity path query across order evidence, relationship candidates, and curated relationships.

**Architecture:** Keep `graph_service.py` as the graph boundary. Build a bounded in-memory adjacency list from existing SQLite tables, expose thin FastAPI adapters, and add Streamlit controls that render tables first.

**Tech Stack:** Python 3.12, SQLite, FastAPI, Streamlit, pytest, ruff.
