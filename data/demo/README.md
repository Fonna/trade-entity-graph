# Demo Data

Generated by `scripts/generate_demo_data.py` for the M8 acceptance flow.

- `demo_entities.csv`: about 50 importable company entities.
- `demo_orders.csv`: order evidence rows that generate P0 role edges.
- `demo_relationship_candidates.csv`: supplemental candidates resolved by canonical name.

## Local Demo Startup

From the repository root, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_demo.ps1
```

The script starts FastAPI at `http://127.0.0.1:8000` and Streamlit at `http://127.0.0.1:8501`. If the default SQLite database does not exist yet, it initializes the schema and imports this demo data. Use `-PrepareDemoData` to import demo rows into an existing database. Service logs are written to `data/processed/logs/`.
